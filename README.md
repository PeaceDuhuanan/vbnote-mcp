# Vbnote MCP Server

Vbnote is a remote Model Context Protocol (MCP) server for searching, browsing, summarizing, and reading transcripts from your private Vbnote library.

## Capabilities

- Search and browse notes in your Vbnote library
- Read note content and transcripts
- Summarize relevant private knowledge after user authorization

## Connection

- **Remote endpoint:** https://4a08142c38dbe374195d41c04562d9f8.nebulab.app/mcp
- **Transport:** Streamable HTTP
- **Authentication:** OAuth 2.0 user authorization

## MCP Registry

- **Registry name:** `io.github.PeaceDuhuanan/vbnote`
- **Current version:** `0.1.0`
- **Manifest:** [server.json](./server.json)

## Repository scope

This public repository contains only the metadata required for discovery and client integration. The Vbnote service implementation is maintained in a private repository.
